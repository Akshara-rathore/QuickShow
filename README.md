# QuickShow 🎬

A full-stack MERN movie ticket booking platform with seat selection and secure online payments.

## 🔥 Features
- Browse movies and showtimes
- Interactive seat selection
- Booking management system
- Secure Stripe payment integration
- Admin dashboard for managing shows

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- Payment: Stripe
- Background Jobs: Inngest

## 🚀 How it Works
1. User selects movie and showtime  
2. Chooses seats  
3. Proceeds to payment  
4. Booking is confirmed
